# S03-06 — Mutations reproductibles

Deux graines fixes pilotent chacune au moins 10 000 mutations add/connect/
disconnect/remove/mark/unmark, avec un PRNG entier défini dans le test pour
reproduire la même séquence sur les plateformes. Un préfixe déterministe
garantit les cas Aux, canaux hors Config, fan-out, doublon, occupation, cycles,
ports invalides, IDs inconnus et double déconnexion. Le nombre de Node vivants
est borné à 12 ; les identités émises continuent d’augmenter sans réutilisation.

Le modèle de test possède ses listes d’identités, couples et marqueurs, et sa
fermeture transitive indépendante. Il ne demande pas à la production de
prédire les résultats. Après chaque opération, comparer les ensembles exacts,
l’occupation et l’acyclicité ; une erreur conserve l’état et son code attendu.
Chaque échec affiche seed, step, opération et valeurs du candidat.

Deux générations structurelles sont conservées périodiquement sur contrôle :
un Node retiré mais encore emprunté reste vivant. Les identités attendues des
plans viennent du modèle ; leur libération et collectRetiredNodes vérifient les
destructions exactement une fois sur contrôle. Les vues ne sont pas retenues
entre éditions. Aucun backend ou exec/process n’est utilisé et les ressources
de test ne survivent pas à leur propriétaire. La PR dépend de S03-05.

Validation : **187/187 tests passent** en C++26 et ASan/UBSan avec détection des
fuites. Deux tests paramétrés exécutent **20 000 mutations** (graines
0xC0FFEE42 et 0x5EED1234), dont un préfixe de 35 commandes garantissant tous les
cas requis. Toutes les catégories et commandes ont des témoins, chaque Node
est détruit une fois sur contrôle et aucun process n’est appelé. Revue du
modèle et du runner sans défaut bloquant. Logs s03-sequence-native/sanitized,
préfixe S03-06 ; diff --check passe.
