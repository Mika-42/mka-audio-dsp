# S03-02 — Canaux non déclarés

Les layouts décrivent le traitement effectif, jamais une liste d’autorisation
pour connect. Les arêtes Out→In/Aux de canaux 0 ou 65535 restent stockées avec
Config vide ou non contiguë {2,6}. Les contrôles de ports, Node, occupation et
cycle continuent de s’appliquer à ces arêtes. Le compilateur ne matérialise que
les buffers déclarés ; une production logique non déclarée se lit au silence.

`DAG::setConfig(NodeID,const Config&) -> Result` modifie le snapshot du Node
sur contrôle sans changer identité/adresse, connexions ou marqueurs. Node absent
retourne NodeNotFound ; tout plan empruntant le Node entraîne NodeInUse. Après
retraite/quiescence de tous ces plans, valider la nouvelle Config, copier une
candidate puis transférer sans exception. Un échec de validation/allocation ne
change rien. La copie est indépendante des modifications ultérieures du caller.

Ce contrôle conservateur préserve S01-07 : aucun layout ni état DSP utilisé
par un plan n’est modifié. Les références aux éléments des anciens vecteurs
Config sont invalidées après succès ; les accès externes doivent être arrêtés.
Le DAG possède toujours ses Node et les plans les empruntent. Aucun setter
direct n’est ajouté à Node, ni édition/allocation/verrou dans un callback.
Le setter ne prépare pas le DSP du dérivé : le caller doit assurer sur contrôle
qu’il sait traiter le nouveau layout avant de compiler un nouveau plan.
La PR dépend de S03-01 ; cette fiche seule est ajoutée à la branche précédente.
