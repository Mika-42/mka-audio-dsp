# S03-03 — Ordre topologique total stable

`topologicalOrder(const DAG&) -> expected<vector<NodeID>,GraphError>` s’exécute
sur contrôle, sans mutation. Kahn utilise une file de priorité NodeID croissant
à chaque extraction : un Node nouvellement disponible passe avant tout Node
disponible de plus grand ID. Exemple : source 2 débloque 1, avec 3 isolé,
l’ordre est 2,1,3, et non le parcours par couches 2,3,1.

Tous les Node apparaissent une fois, isolés inclus. Toutes les arêtes In/Aux,
parallèles et hors Config participent aux degrés/précédences. Une extraction
incomplète retourne CycleDetected. Les snapshots internes possèdent seulement
NodeID/Connection/outputIDs, sans posséder de Node ou samples. L’overload interne
sur snapshot permet une fixture cyclique sans contourner les invariants du DAG.

La compilation utilise exactement cet ordre pour ses Node* empruntés. Les
vues de couches sont des étapes sérielles unitaires de cet ordre total, pas des
niveaux BFS : aucune parallélisation n’était livrée. Le plan et son propriétaire
gardent les préconditions de durée de vie/quiescence précédentes. Le coût moyen
est O((V+E)log V), avec stockage temporaire O(V+E), sur contrôle uniquement.
Les erreurs de capacité/allocation sont structurées ; aucun process/callback
n’est invoqué pendant le tri ou la compilation structurelle.

Les entiers et tableaux temporaires appartiennent au caller/contrôle ; les
vues tasks/layer appartiennent au plan. Aucun pointeur propriétaire n’est
transféré au traitement audio. La PR dépend de S03-02.

Validation : **182/182 tests passent** en C++26 et ASan/UBSan avec détection
des fuites. Six tests vérifient le min-heap global (LWW 2,1,3), vide/isolés,
diamant, fan-out, relations parallèles, permutations d’identités non contiguës,
arêtes insérées en sens inverse et cycles/entrées invalides en fixture. Un
test injecte chaque échec d’allocation du wrapper sans mutation du graphe ni
du plan existant. Logs s03-sequence-native/sanitized, préfixe S03-03.
Les helpers et signatures ont été relus ; diff --check passe.
