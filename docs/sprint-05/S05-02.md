# S05-02 — Silence partagé en lecture seule

Le nouveau pool prépare une allocation distincte de `maxFrames` floats nuls,
exposée uniquement par `const float* silence() const noexcept`. Aucun BufferId
ne la désigne : elle est exclue de toute affectation de sortie et de freelist.
Le budget et `allocatedBytes()` incluent cette réserve, même avec zéro slot.
Zéro frame autorise un pointeur nul sans accès sample.

Les deux allocations sont temporaires jusqu'au commit commun. Un refus de la
seconde allocation préserve le pool et le silence précédents. Les tests couvrent
1/128/4096 frames, 64 usages successifs, l'écriture dans tous les slots sans
altérer le silence, et zéro opération heap/mutex dans la fenêtre de lecture.
Les tests `SilenceInputs` du moteur existant vérifient déjà le partage entre
Nodes, les entrées hors layout et le rebind des sources aux vraies entrées.
S05-07 remplacera leur réserve historique par ce pool.
