# S07-06 — Durée de vie des Nodes à travers toutes les générations

Le DAG reste l'unique propriétaire des Node. Le comptage de borrows existant
protège les Nodes retirés du graphe souhaité tant qu'une génération quelconque
les référence : Active/Ready/Pending, ancien plan non récupéré ou copie externe.
ACK n'est donc jamais interprété comme une preuve de disparition de tous les
Node*. Seule collectRetiredNodes sur contrôle peut détruire la propriété différée.

Les tests conservent une copie externe de B après les retraits successifs d'A et
B, puis rendent ses samples avant de la libérer. D'autres cas couvrent un échec
de remplacement après suppression et abandon de Ready, 32 cycles add/remove,
suppression avant toute référence, IDs non réutilisés et destructeurs comptés.
Aucun Node n'est détruit dans les fenêtres audio. Les tests de cette fiche sont
inclus dans les suites ASan/UBSan et TSan finales.
