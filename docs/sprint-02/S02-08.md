# Sprint 2, fiche 8 — S02-08 : intégration du DAG éditable

**Implémentée, en attente de validation.** [Trello #16](https://trello.com/c/fgNXIV95).
PR vers main dépendante de S02-07 ; fusion manuelle après les fiches 4 à 7.

Un GoogleTest construit les quatre types Source, Gain, Mix et Output, avec
Source.Out → Gain.In → Mix.In → Output.In et une liaison Aux supplémentaire.
Il exerce le fan-out, les indices hors Config et les refus de direction,
doublon, occupation et cycle. Après chaque étape, il compare les Node connus,
les valeurs Connection et la collection outputNodes complète.

Le scénario déconnecte un couple exact, vérifie true puis false et la
conservation des autres liaisons entre mêmes Node. Il retire ensuite un Node
marqué et vérifie ses arêtes incidentes et son marqueur, sans toucher aux
autres. Les références aux collections ne survivent pas aux éditions ; les
valeurs attendues sont indépendantes du stockage privé.

Le helper d’inspection compile uniquement la structure sur contrôle afin de
vérifier l’ensemble des Node et leurs adresses, sans préparer de buffers audio.
Son plan temporaire est détruit avant la mutation suivante. Le test n’appelle
jamais exec, process, thread audio ou backend physique et n’utilise aucun état
global. Les quatre ressources Node sont détruites exactement une fois sur le
thread de contrôle. La documentation Doxygen de compile() explicite ce contrat.

Cette dernière fiche n’ajoute aucune API d’exécution ou de publication ; elle
vérifie ensemble les contrats livrés séquentiellement par les fiches précédentes.

Validation finale : **164/164 tests passent** en C++26 Debug Clang19/libc++19
et sous ASan/UBSan avec détection des fuites ; **156/156 tests fonctionnels
passent sous TSan**. Aucun diagnostic ni test désactivé dans les configurations
native/ASan. Les huit tests séparés d’interception new/delete sont validés en
natif et ASan, hors TSan pour éviter le conflit d’intercepteurs documenté dans
S02-06. La revue indépendante du scénario et des durées de vie ne relève aucun
défaut bloquant ; `git diff --check` passe.

Les commandes de reproduction sont dans les fiches précédentes : CMake C++26,
Clang19/libc++19, Ninja, GoogleTest1.17. Les logs par fiche sont hors dépôt dans
les builds s02-sequence-native/sanitized/threadsanitized, préfixe S02-08 pour
la dernière validation. Le scénario d’intégration seul est sélectionnable par
CTest `-R '^dsp.EditableDAGIntegration'`, sans backend.
