# Sprint 2, fiche 4 — S02-04 : occupation des canaux entrants

**Implémentée, en attente de validation.** [Trello #12](https://trello.com/c/YtF0Vv5A).
Une PR distincte livre uniquement cette fiche. Les suivantes sont autorisées
séquentiellement et dépendront de celle-ci, sans fusion automatique.

L’occupation se déduit de la collection privée `Connection` du DAG souhaité.
Le helper de contrôle `inputOccupied(ChannelID)` compare le champ destination
complet : NodeID, PortType et ChannelIndex. In(B,0), Aux(B,0), In(B,1) et
In(C,0) restent indépendants, y compris avec Config vide. Aucun index mutable
supplémentaire ni réservation de voie backend n’est créé.

`connect(destination, source)` rejette le couple exact déjà stocké par
`ConnectionExists`, avant de rejeter un autre producteur par `InputOccupied`.
Les refus laissent la collection, les Node et les plans inchangés. Le fan-out
d’un même Out est admis vers autant de destinations distinctes que la capacité
le permet. Les erreurs d’allocation restent structurées comme dans S02-03.

Les éditions et la recherche d’occupation sont sur contrôle, avec sérialisation
externe. Le scan n’alloue pas et n’accède pas aux samples. La collection possède
ses valeurs, sans posséder de Node ou buffer. Sa vue const empruntée est
invalidable par les éditions ; copier les valeurs pour conserver un instantané.
Le callback ne lit pas cet état souhaité : il utilise son plan préparé.

La suppression d’une arête ou d’un Node libère immédiatement l’occupation dans
le graphe souhaité puisque celui-ci est l’unique source de vérité. Un ancien
plan garde son routage jusqu’à sa retraite. Cette fiche vérifie la déconnexion
historique par paire de NodeID ; l’API exacte et idempotente est livrée en S02-05.

Validation : **147/147 tests CTest passent**, dont cinq nouveaux tests dédiés,
en C++26 Debug avec Clang19/libc++19 et également sous ASan/UBSan avec détection
des fuites activée. Aucun diagnostic ni test désactivé. Les tests antérieurs
d’injection d’allocation et d’absence d’allocation/libération RT restent verts.
Les logs sont conservés hors dépôt dans les builds s02-sequence-native et
s02-sequence-sanitized, préfixe S02-04. `git diff --check` passe.
