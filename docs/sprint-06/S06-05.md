# S06-05 — Silence physique au début de chaque callback

Le passage de mise à zéro existant est exécuté après validation du bloc et avant
toute opération Node/Delay. Il efface exactement frames floats par sortie
physique, sans toucher le pool ni les échantillons hors de la plage annoncée.
Une voie non écrite reste donc silencieuse. L'effacement est unique par callback,
pas répété entre writers ; la règle LWW est vérifiée dans S06-06.

Les nouveaux tests examinent 0/1/2/6 voies sans Node et un observateur placé
avant le premier writer. Ce dernier écrit seulement les offsets 2/4/6 sur deux
voies. Les autres samples restent nuls. Plusieurs callbacks alternent les
adresses et frames 0/1/8/17/128 sans reset de stockage entre blocs : les samples
hors frames doivent conserver exactement leur valeur précédente, gardes incluses.

Une fenêtre RT reprend les écritures partielles sur six voies sans allocation,
libération ou mutex. Aucun composant ni nom de périphérique n'est imposé.
