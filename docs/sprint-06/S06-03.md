# S06-03 — Inputs physiques directs en lecture seule

Le binding existant expose le tableau physique complet aux sources. Après
S06-01, sa taille est exactement celle du snapshot BackendConfig. Les types
restent `const float*` et `span<const InputChannel>`, avec ChannelID physique
neutre zéro, sans encodage matériel dans le DAG. Aucun nouveau mécanisme de
copie/routage n'est ajouté.

Deux sources aux layouts différents (dont un vide et un indice 65535) lisent
directement la première et la dernière voie physique sur 0/1/2/6 voies. Un Node
est également marqué output. Les tests comparent les adresses pendant process,
les samples des deux productions, les entrées inchangées et la stabilité du
stockage interne après changement de backend. Aucun pointeur backend n'est
conservé dans les Nodes ; les vues callback sont vides au retour.

Un cas zéro frame contient six pointeurs nuls, sans accès sample. Une fenêtre
RT multi-source alterne deux backends sans allocation/libération ni mutex.
