# S06-02 — Sources topologiques préparées

Le compilateur structurel existant produit déjà les indices privés `sourceTasks_`
dans l'ordre topologique déterministe, à partir de toutes les connexions In/Aux
validées. La préparation audio capture les mêmes rôles. Aucun nouveau parcours
du DAG n'est ajouté au callback et aucun rôle n'est inféré depuis layoutInput.

Deux tests dédiés couvrent les sources isolées ou avec successeur, un Aux entrant,
un layout vide, une arête Aux hors layout et un Node à la fois source et output
avec successeur. Les sources reçoivent six vrais inputs, les autres leurs seuls
inputs logiques. Les indices restent à la même adresse pendant les callbacks.

Une édition du graphe change uniquement le plan suivant ; une préparation refusée
conserve la liste et le routage de l'ancien plan. Les tests vérifient aussi que
le nombre de Nodes/connexions ne comporte aucun ajout matériel. Cette fiche
complète la couverture du mécanisme existant, sans modifier sa production.
