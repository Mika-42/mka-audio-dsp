# S06-06 — Last Writer Wins par sample

Les Nodes marqués output écrivent déjà directement les mêmes pointeurs physiques,
dans l'ordre topologique global. Aucun mix, réservation de voie ou copie de bloc
après process n'est ajouté. Une écriture tardive remplace uniquement les samples
effectivement écrits ; les trous conservent les valeurs antérieures ou le zéro
initial du callback.

Le fixture partagé comporte trois writers, un Node non marqué et un successeur
logique. Le consommateur est créé avant son producteur ; l'ordre attendu est
explicitement vérifié et reste identique après inversion de l'ordre d'insertion
des arêtes. Une équation indépendante calcule chaque sample : premier writer
complet, deuxième aux offsets 2/4 d'une voie, troisième sur d'autres voies et
sous-plages. Les canaux communs et distincts, les trous, les gardes, deux backends
et frames 0/1/8/128 sont comparés. Les sorties logiques restent intactes pendant
la lecture du successeur et le Node non marqué ne voit aucun backendOutput.

Le même montage est exécuté dans une fenêtre RT sans new/delete ni mutex.
